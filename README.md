# CH.FANDRICH Hörbuch Studio

Mobile, GitHub-basierte Web-App zur Vorbereitung und Produktion von Hörbuchprojekten.

## Version 7.0
- Manuskript-Import für TXT und Markdown
- automatische Kapitelerkennung und Kapitelverwaltung
- Wort-, Zeichen- und Laufzeitschätzung
- Browser-Sprachausgabe mit Stimmenauswahl
- Tempo- und Tonhöhensteuerung
- Sprecherprofile: Warm, Erzähler, Fantasy, Abenteuer
- KI-Hörprobe
- Aussprachekorrekturen pro Projekt
- einstellbare Absatzpausen
- Produktionsprüfung für alle Kapitel
- Produktionsfortschritt
- Smartphone-Mikrofonaufnahme mit Wiedergabe und Download
- Kapitel-Audio für MP3, WAV und M4A
- lokales Speichern und JSON-Projektexport

## Sicherheit
Das Studio wird ausschließlich über GitHub entwickelt. Geheimnisse oder API-Schlüssel werden nicht in GitHub Pages oder im Browsercode gespeichert.

## Nächster Ausbau
Sichere TTS-Erzeugung und Hörbuch-Mastering über GitHub-basierte Workflows, ohne öffentliche API-Schlüssel im Frontend.
