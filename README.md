# CH.FANDRICH Hörbuch Studio

Mobile Web-App zur Vorbereitung von Hörbuchprojekten.

## Version 1.0
- Kapitelverwaltung
- Manuskript-Editor
- Wort-, Zeichen- und Laufzeitschätzung
- Browser-Sprachausgabe mit Stimmenauswahl
- Tempo-Steuerung
- lokales Speichern des Projekts
